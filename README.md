# DIO_podcast_process
Atividade do curso de IA DIO
O projeto consiste na criação de um podcast utilizando ferramentas de Inteligência Artificial(IA) para a criação do nome, imagem do projeto, roteiro e gravação do áudio.
O podcast criado trata do tema gestão de processos e melhoria continua utilizando o chatgpt para a criação de conteúdo, o copilot para gerar imagens e o elevenlabs para narração.
